# Make WRECK yours: brand questionnaire

WRECK is a working name and visual direction, not a locked identity. Answer these questions in plain language; “keep the current default” is a perfectly good answer. The maintainer can then update the name, acronym, README, badges, icon, hero artwork, colors, and repository metadata consistently.

1. **Name:** Keep **WRECK**, or do you want another project/repository name? If changing it, what should the GitHub repo be called?
2. **Acronym:** Is **Web Reverse Engineering & Cloning Kit** the right expansion? If not, which words should the acronym emphasize (for example: agent, application, analysis, rebuild, evidence)?
3. **Who is this for?** Choose the main audience: solo developers, AI-agent builders, security/research teams, agencies, or another group. What should a first-time visitor understand within five seconds?
4. **Personality:** Which direction feels most like you: clean professional developer tool, bold cyber / reverse-engineering lab, friendly maker toolkit, enterprise platform, or a style you describe?
5. **Visual identity:** Keep the current ink-navy / electric-cyan / orange palette and abstract investigation-to-interface artwork, or provide your preferred colors, symbols, and logo references.
6. **Voice and tagline:** Keep “Investigate how an authorized app works. Turn evidence into a tested, modern rebuild.”, or what short promise should the README lead with?
7. **Public identity:** Should the README show the GitHub organization/team name, a personal creator name, or remain organization-neutral? Do not share private personal details you do not want published.

## Current defaults

- Name: WRECK
- Expansion: Web Reverse Engineering & Cloning Kit
- Audience: developers and AI coding-agent users
- Style: polished developer-tool branding; navy, cyan, and orange
- Tagline: “Investigate how an authorized app works. Turn evidence into a tested, modern rebuild.”
- Attribution: original upstream authors and licenses remain visible regardless of rebranding.
